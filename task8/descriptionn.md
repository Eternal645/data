# Задание 2. Изучение структуры таблиц

## 1. Учёт закупок

Основной источник данных -  bm_StorageOperations - записи о движении продукции.

- ID - идентификатор операции (4780421)
- DocumentID - идентификатор документа (388235)
- ProductID - идентификатор товара (4368)

Дополнительно рассматриваются таблицы:
bm_JournalBarnetDocs - документы, связанные с операциями.

- ID - идентификатор документа (1216)
- ShiftID - идентификатор смены (65)
- DocumentTypeID - код типа документа (1)

bm_StorageOperations_Table - записи о движении продукции.

- ID - идентификатор операции (134198)
- DocumentID - идентификатор документа (388540)
- OperationID - код вида операции (2)
- StorageID - идентификатор склада (41)
- ProductID - идентификатор товара (4345)

product - каталог продукции.

- id - идентификатор товара (4337)
- productid - артикул товара (1204073)
- description - наименование товара (Бананы)
- vendorid - идентификатор поставщика (107)
- flaging - признак состояния товара (1)

vendors - информация о поставщиках.

- id - идентификатор поставщика (90)
- clientid - название поставщика (Габур)
- clientgroup - категория поставщика (32)
- serialnumber - порядковый номер (0)
- firstname - имя поставщика (ИП Габур)

bm_JournalTypeDocuments - классификатор документов.

- ID - идентификатор вида документа (1)
- Description - обозначение типа (Ввод состава нового рецепта)
- JournalID - идентификатор журнала (1)
- IsParent - показатель родительского типа (0)

bm_Contracts - сведения о договорах.

- ID - идентификатор договора (данных нет)
- ParentType - категория родительского объекта (данных нет)
- CompanyID - идентификатор организации (данных нет)
- VendorID - идентификатор поставщика (данных нет)

storages - перечень складов.

- id - идентификатор склада (41)
- CompanyID - идентификатор организации (6)
- description - наименование склада (Склад)
- CityID - идентификатор города (NULL)

bm_StorageOperationsType - справочник видов движений.

- ID - идентификатор вида операции (1)
- Description - наименование операции (Поступление)
- Factor - множитель операции (1)
- DateAdd - время создания записи (2013-01-15 15:19:12.517)


Выявленные связи:
- bm_StorageOperations.DocumentID ссылается на bm_JournalBarnetDocs.ID - позволяет определить документ операции
- bm_JournalBarnetDocs.DocumentTypeID соответствует bm_JournalTypeDocuments.ID - позволяет узнать тип документа
- bm_StorageOperations.OperationID соответствует bm_StorageOperationsType.ID - позволяет получить вид складской операции
- bm_StorageOperations.StorageID соответствует storages.id - указывает склад выполнения операции
- bm_StorageOperations.ContractID может соответствовать bm_Contracts.ID - возможная привязка к договору; таблица договоров пустая


## 2. Данные о продажах

Основной источник данных -  product - каталог продукции.

- id - идентификатор товара (4337)
- productid - артикул товара (1204073)
- description - наименование товара (Бананы)

Дополнительно рассматриваются таблицы: 
pricelist - ценовые записи.

- id - идентификатор записи (113681)
- DocumentID - идентификатор документа (142417)

vw_SalesTicketInfo - представление с данными о чеках и проданных позициях.

- ID - идентификатор записи (1675807)
- TicketNumber - идентификатор чека (10329777)
- TicketDate - дата и время продажи (2020-11-11 23:27:34.000)
- ProductType - категория продукции (Блюдо)
- BludoID - идентификатор блюда (4520)

Представление vw_SalesTicketInfo используется для анализа фактических продаж.

Выявленные связи:
- pricelist.productid соответствует product.id - связывает цену с товаром
- vw_SalesTicketInfo показывает информацию о проведённых продажах: чек, дату и позицию


## 3. Работа с поставщиками

Основной источник данных -  vendors - информация о поставщиках.

- id - идентификатор поставщика (90)
- clientid - название поставщика (Габур)
- clientgroup - категория поставщика (32)

Дополнительно рассматриваются таблицы: 
bm_StorageOperations - записи о движении продукции.

- ID - идентификатор операции (4780421)
- DocumentID - идентификатор документа (388235)
- OperationID - код вида операции (1)

bm_JournalBarnetDocs - документы, связанные с операциями.

- ID - идентификатор документа (1216)
- JournalID - идентификатор журнала (1)
- ShiftID - идентификатор смены (65)
- DocumentNumber - идентификатор документа в журнале (1)
- Period - дата оформления документа (2013-07-23 10:00:00.000)

Выявленные связи:
- bm_StorageOperations.VendorID соответствует vendors.id - определяет поставщика операции
- bm_StorageOperations.DocumentID соответствует bm_JournalBarnetDocs.ID - позволяет определить документ операции
- Пока не обнаружены сведения, необходимые для точного вычисления долгов поставщикам

## 4. Сведения о персонале

Основной источник данных -  personnel - сведения о работниках.

- personid - идентификатор сотрудника (897)
- firstname - имя (Администратор Barnet)
- lastname - фамилия (пусто)

Дополнительно рассматриваются таблицы: 
bm_BonusHistory - журнал бонусных операций.

- ID - идентификатор записи (1)
- ClientID - идентификатор клиента (3352)
- ActionName - вид действия (User)

bm_WorkHours - данные об отработанном времени.

- ID - идентификатор записи (данных нет)
- ShiftID - идентификатор смены (данных нет)
- PersonID - идентификатор сотрудника (данных нет)
- PersonName - имя работника (данных нет)


Выявленные связи:
- bm_BonusHistory.PersonID соответствует personnel.personid - позволяет сопоставить бонусную запись и работника
- bm_WorkHours.PersonID предположительно относится к personnel.personid - предполагаемая связь, но записей в учёте времени нет

## 5. Учёт остатков

Основной источник данных -  bm_StorageOperations_Table - записи о движении продукции.

- ID - идентификатор операции (134198)
- DocumentID - идентификатор документа (388540)
- StorageID - идентификатор склада (41)

Дополнительно рассматриваются таблицы: 
bm_JournalBarnetDocs - документы, связанные с операциями.

- ID - идентификатор документа (1216)
- ShiftID - идентификатор смены (65)
- DocumentTypeID - код типа документа (1)

bm_Journal_Details - строки журнала товаров.

- ID - идентификатор записи (11530445)
- SourceID - идентификатор источника (1675591)
- ProductID - идентификатор товара (4407)
- Quantity - объём в единицах (1.0000)
- StorageID - идентификатор склада (41)

Выявленные связи:
- bm_StorageOperations_Table.DocumentID соответствует bm_JournalBarnetDocs.ID - даёт документ, к которому относится операция
- bm_Journal_Details хранит ProductID и Quantity, по которым можно определить товар и количество
